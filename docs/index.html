PAY.JP iOS SDK

オンライン決済サービス「PAY.JP」のiOSアプリ組込み用のSDKです。

【重要】CocoaPods での配信終了について

CocoaPods Trunk が 2026年12月2日に読み取り専用となるため、今後 CocoaPods では新しいバージョンを配信できなくなります。 最新バージョンをご利用いただくには、Swift Package Manager または Carthage へ移行してください。 詳細はCocoaPods 配信終了についてを参照してください。

最新バージョンでは以下を実現するための機能が提供されています。 詳細はドキュメントを参照してください。

インストール

Swift Package Manager (推奨)

Xcode でプロジェクトを開き、以下の手順で追加してください。

  1. メニューの File > Add Package Dependencies… を選択
  2. 検索欄に https://github.com/payjp/payjp-ios.git を入力
  3. Dependency Rule でバージョンを指定し、Add Package を選択
  4. 利用するターゲットに PAYJP を追加

Package.swift で管理している場合は、以下のように記述してください。

dependencies: [
    .package(url: "https://github.com/payjp/payjp-ios.git", from: "<バージョン>")
],
targets: [
    .target(
        name: "YourTarget",
        dependencies: [
            .product(name: "PAYJP", package: "PAYJP")
        ]
    )
]

Carthage

Carthage でインストールする場合、以下のように記述してください

github "payjp/payjp-ios"
Carthageサンプルアプリのビルド example-swift-carthageターゲットをローカルでビルドする場合は、fastlaneを使用してください： “`bash bundle exec fastlane ios build_carthage_swift_example ”` このlaneは以下を自動的に実行します： 1. PAYJP.xcframeworkの作成（iOSデバイス＋シミュレーター用） 2. 依存ライブラリ（PhoneNumberKit等）のCarthageビルド 3. example-swift-carthageアプリのビルド 注: Package.swiftとの競合により、`carthage bootstrap`だけではビルドできません。fastlaneを使用してください。

CocoaPods (非推奨)

【重要】 CocoaPods での新しいバージョンの配信は終了予定です。CocoaPods 配信終了についてを参照し、Swift Package Manager または Carthage へ移行してください。

CocoaPods でもインストールすることができます。

pod 'PAYJP'

CocoaPods 配信終了について

CocoaPods の公開リポジトリ (Trunk) が 2026年12月2日に読み取り専用になることに伴い、PAY.JP iOS SDK は CocoaPods での配信を終了します。

  • 配信終了前に公開済みのバージョンは、引き続き CocoaPods でインストールできます。
  • 配信終了後に公開される新しいバージョンは、CocoaPods では取得できません。
  • 最新のバージョンや機能追加・修正を利用するには、Swift Package Manager または Carthage への移行が必要です。

CocoaPods から Swift Package Manager への移行

  1. Podfile から pod 'PAYJP' を削除し、pod install を実行する
  2. 上記のSwift Package Managerの手順で PAYJP を追加する
  3. アプリのビルドと動作を確認する
